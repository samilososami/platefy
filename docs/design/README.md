# Propuestas visuales

Conceptos generados antes de implementar las cartas con la herramienta integrada de imágenes. La herramienta disponible no permite seleccionar un identificador de modelo: no se afirma una versión GPT Images concreta.

- `ko-concept.png`: papel crema, tinta, rojo y fotografía de sushi.
- `vita-concept.png`: verdes, tipografía editorial y cocina vegetal.
- `ko-figma-menu.png`: carta original exportada de Figma, nodo 3:3.
- `assets.md`: fotografías individuales, prompts y datos de Figma.

Adaptación: se conservan jerarquía, composición, paletas y tipos de fichas de los conceptos; se añaden búsqueda y detalle accesible para consultar ingredientes. El botón de la ficha abre información (no un carrito). No se añadieron rótulos japoneses o afirmaciones que no figuraban en el contenido fuente. Las fotografías finales se generaron por separado para cada plato.
